# prostavAI


Новостной портал города **Ставрополя**.

Проект на **React + TypeScript** (Vite) с интерфейсом на **Ant Design**.

На первом этапе используем моковые данные и эмулируем вызовы API через `fetch`-подобный слой (без настоящего бэкенда). Позже заменим моки на реальные эндпоинты.

## Запуск

```bash
npm install
npm run dev
```
=======
Это новостной портал города **Ставрополя**.

Здесь будут публиковаться актуальные городские новости, анонсы событий, полезные материалы для жителей и гостей, а также важные объявления.

Цель проекта — собрать всё значимое в одном месте: быстро, понятно и без лишнего шума.
